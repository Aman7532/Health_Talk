# Kibana Dashboard Setup for Healthcare Chatbot

This document explains the Kibana dashboard setup for the Healthcare Chatbot application and how to verify that it's working correctly.

## Dashboard Overview

The Kibana dashboard for the Healthcare Chatbot includes two main visualizations:

1. **Common Log Messages**: A table visualization showing the most frequently occurring log messages in the Healthcare Chatbot logs.
2. **Execution Times**: A histogram visualization showing the distribution of execution times using the `execution_time` field from the logs.

## Automated Setup

The Ansible deployment script has been updated to automatically create these visualizations during deployment. The setup process:

1. Waits for Kibana to be ready
2. Creates an index pattern for the Healthcare Chatbot logs
3. Creates the Common Log Messages visualization
4. Creates the Execution Times visualization
5. Assembles them into a dashboard

## Accessing the Dashboard

To access the Kibana dashboard:

1. Set up port forwarding for Kibana:
   ```bash
   kubectl port-forward -n healthcare-chatbot svc/kibana-service 30002:80
   ```

2. Open Kibana in your browser:
   ```
   http://localhost:30002
   ```

3. Navigate to the "Dashboard" section and look for "Healthcare Chatbot Monitoring"

## Manual Setup (if needed)

If the automated setup doesn't work, you can manually create the visualizations:

1. In Kibana, go to Management > Stack Management > Index Patterns
2. Create a new index pattern with:
   - Name: `healthcare-chatbot-*`
   - Time field: `@timestamp`

3. Go to Visualize and create:
   - A table visualization for "Common Log Messages" using the message.keyword field
   - A histogram visualization for "Execution Times" using the execution_time field

4. Create a new dashboard and add both visualizations

## Troubleshooting

If you don't see data in the visualizations:

1. Make sure logs are being generated by the Healthcare Chatbot
2. Verify that Filebeat is collecting the logs correctly
3. Check that Elasticsearch is receiving and indexing the logs
4. Ensure the index pattern matches the actual indices in Elasticsearch

## Configuration Files

The following files have been updated to support the Kibana dashboard setup:

- `ansible-deploy.yml`: Updated to use a more robust approach for setting up the Kibana dashboard
- `k8s/config/kibana-setup-scripts-configmap.yaml`: Contains the setup script for creating the visualizations
